lifecourse is an open-source Python microsimulation model designed to evaluate the
cost-effectiveness and budget impact of health interventions — particularly
genomic testing policies — across simulated individual life courses.

The model simulates individual-level health trajectories using discrete-time
annual cycles, producing the incremental costs, quality-adjusted life years
(QALYs), and cost-effectiveness metrics needed for health technology assessment
(HTA) submissions and policy analysis.

## Quick Start

```python
from lifecourse.model.parameters import POP_SIZE
from lifecourse.analysis.run_helpers import run_sim

# Run a deterministic simulation
params = {
    "familial_prop": 0.15,
    "yield_wgs": 0.78,
    "u_diag": 0.85,
    "cost_inp_severe": 50000,
}
years = list(range(2024, 2055))
dcost, dqaly = run_sim(params, pop_size=POP_SIZE, years=years)
icer = dcost / dqaly if dqaly != 0 else 0

print(f"Incremental Cost: {dcost:,.2f}")
print(f"Incremental QALYs: {dqaly:.4f}")
print(f"ICER: {icer:,.2f}")
```

## Architecture Overview

lifecourse uses a **discrete-time annual-cycle microsimulation** architecture:

1. **Population System** — initializes individuals with age, sex, SES quintile,
   and disease risk parameters.
2. **Annual Step** — each year, the model applies mortality hazards, disease
   progression, diagnosis probabilities, treatment costs, and QALY calculations.
3. **Cost and Outcome Accumulation** — costs and QALYs are accumulated over the
   simulation horizon for both retrospective (standard care) and prospective
   (intervention) arms.
4. **Analysis Layer** — deterministic scenarios, PSA, EVPI, EVPPI, EVSI,
   subgroup analysis, budget impact, equity analysis, and MCDA.
