## Key Modules

### Engine Registry (`lifecourse.engine_contract`)

```python
from lifecourse.engine_contract import (
    SimulationEngine,          # Protocol for engine implementations
    SimulationEngineSpec,      # Registry entry with metadata + runner
    EngineRunResult,           # Execution result with diagnostics
    EngineResolution,          # Resolved engine selection
    list_engine_ids,           # List registered engine IDs
    get_engine,                # Get engine spec by ID
    register_engine,           # Register a custom engine
    select_engine,             # Resolve engine by ID or default
    default_engine_metadata,   # Get default engine metadata
    run_registered_simulation, # Execute via registry
    UnknownEngineError,        # Raised for unknown engine IDs
)
```

### CLI (`lifecourse.cli` and `lifecourse.main`)

```python
# Simple CLI for direct scenario running
python -m lifecourse.cli [scenario_name] [options]

# Full workflow CLI with all analysis modules
python -m lifecourse.main [options]
```
