# HEOML v0.1 Fixtures

This directory holds small reference bundles used to validate the HEOML v0.1
schema and to keep examples deterministic.

## Structure

- `normative/`: canonical fixture bundles that should validate against the
  current v0.1 schema.

These fixtures are intentionally small and human-reviewable. They are designed
to support schema validation, fixture-based tests, and future extraction of the
embedded HEOML subtree into a standalone repository.
